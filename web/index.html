¿Qué significa cada indicador?
Rendimiento
Cuánto cambió el precio entre el inicio y el final del periodo elegido.
Rango
El precio más bajo y el más alto que alcanzó en el periodo.
Volatilidad anualizada
Qué tanto se mueve el precio de un día a otro, expresado por año. Más volatilidad significa más riesgo.
Caída desde el máximo
Qué tan lejos está hoy del precio más alto del periodo.

Sello de Confianza para exchanges

Para el usuario colombiano, la pregunta no es si la tecnología funciona, sino en quién confiar. El Sello responde esa pregunta con una evaluación independiente.

  1. Diagnóstico. Revisamos tus controles de seguridad frente a ISO 27001 y la regulación local.
  2. Plan de cierre. Te entregamos las brechas encontradas y cómo resolverlas.
  3. Sello y monitoreo. Publicamos tu Sello y lo mantenemos vigente con datos de mercado verificables, como los de esta página.

Tus datos de contacto quedan en una base privada. Ningún servicio público de este sitio puede leerlos.

De dónde sale cada dato

Binance envía los precios a nuestro servicio de ingesta en Azure (España). Se guardan en una base de datos privada, sin acceso desde Internet, y una API de solo lectura los entrega a esta página. El histórico lo actualiza un trabajo programado que solo se enciende mientras trabaja.

Información de referencia, no es asesoría de inversión. Datos de mercado: Binance. Código abierto en GitHub.
